Mapa de Open MCT para conectar a Percy

Open MCT es el tablero de un centro de control de misión, hecho página web: tú le dices de dónde vienen los datos de una nave, y él los muestra en gráficas, tablas y pantallas que el equipo arma a su gusto, en vivo o mirando hacia atrás en el tiempo.

El plan

Cómo conectamos Percy

Nuestra simulación 3D ya sabe en todo momento dónde está Percy, qué tan rápido va y hacia dónde mira. Estos son los pasos para que esos números aparezcan en una pantalla de Open MCT.

  1. Elegir qué datos mandamos

    Velocidad (m/s), rumbo (grados), posición x y z (metros) e inclinación. La simulación ya los entrega con estadoRover(), en nuestro src/main.js.

  2. Tender el "cable" entre la simulación y Open MCT

    Si las dos páginas se sirven desde el mismo sitio, el navegador las puede comunicar directamente (con un canal llamado BroadcastChannel), sin servidor extra. La simulación publica un dato varias veces por segundo.

  3. Crear nuestro plugin percy

    En un archivo propio, fuera del repositorio de la NASA. Adentro van las piezas 1 y 2: el tipo percy.sensor y la carpeta "Percy" con un objeto por sensor. Cada objeto lleva telemetry: {}, o Open MCT lo trata como carpeta (src/plugins/plot/configuration/SeriesCollection.js:54-58).

  4. Escribir la ficha de cada sensor

    Pieza 3: un campo utc (la hora, eje X) y un campo valor con su unidad (eje Y).

    { key: 'utc',   format: 'utc', hints: { domain: 1 } },
{ key: 'valor', unit: 'm/s',   hints: { range: 1 } }

  5. Escribir el proveedor

    Pieza 4: subscribe escucha el "cable" y pasa cada dato a Open MCT. request devuelve lo que ya guardamos entre la hora de inicio y la de fin que pida la gráfica. Solo atiende objetos de Percy, para no quitarle datos a otros (src/api/telemetry/TelemetryAPI.js:169: el último proveedor registrado tiene prioridad).

  6. Instalar el plugin y arrancar

    Una línea openmct.install(PercyPlugin()) en la página, antes de openmct.start(), igual que el generador de ejemplo (index.html:104).

  7. Armar la pantalla y probar

    Abrir Open MCT, entrar a la carpeta "Percy", abrir "Velocidad" como gráfica, poner el reloj en tiempo real y manejar el rover con WASD. La línea debería subir y bajar mientras manejamos.

Cuidado con estas trampas

  • La hora va en milisegundos (un número), no como texto. Si no, la gráfica no la entiende.
  • Dos datos con la misma hora: el segundo se descarta en silencio (PlotSeries.js:453-459).
  • Nunca mandar un dato vacío: Open MCT da error (TelemetryAPI.js:584-588).
  • Para usar la hora marciana (el "sol" de Marte) hace falta un reloj propio; para empezar basta con UTC.
  • Para correr Open MCT junto a nuestro proyecto habrá que instalarlo. Hoy solo se leyó el código, sin instalar nada.
